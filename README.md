# 青衿题库 · 高数 / 大物 AI 伴学

一个**纯静态**的学习辅助网站，基于 DeepSeek API（用户自备 Key），面向**高等数学、大学物理**，
提供：拍照识别、题目解答、举一反三、深度思考、生成模拟卷、继续追问，并内置**南信大往年试卷库**。

> **重要声明（用户自备 Key / BYOK）**
> 本工具本身不提供 AI 服务，也不储存任何 API Key。所有解题、举一反三、模拟卷、拍照识别，
> 均由「**使用者本人填写的 DeepSeek API Key**」调用生成，费用由该 Key 所属账户自行承担。
> Key 只保存在**使用者自己的浏览器**（localStorage）中。作为网站部署者，**你不承担任何 AI 费用**。

## 功能

| 功能 | 说明 |
|------|------|
| **拍照识别** | 拍照/上传题目图片，用 DeepSeek `deepseek-flash` 识别成文字/LaTeX，再解答 |
| **公式预览** | 识别出的 LaTeX 实时渲染成公式，方便核对 |
| **解题** | 思路分析 → 分步解答 → 一题多解 → 易错提醒 → 思维拓展 |
| **举一反三** | 生成「基础变式」+「创新变式」，每道标注思维点并附解答 |
| **深度思考** | 讲透概念本质、多角度审视、创新拓展、梳理知识脉络 |
| **出模拟卷** | 参考试卷库，生成风格相近的完整试卷，含「综合创新题」板块 |
| **继续追问** | 解答后可打开聊天窗继续问，AI 记得前面题目和解答 |
| **试卷库** | 内置往年真题（`static/papers.txt`），出卷/举一反三时自动参考其风格 |

> 拍照识别用 DeepSeek 官方的视觉模型 `deepseek-flash`，**和解题共用同一个 Key**，不需要额外配置。

## 快速开始（本地预览）

**要求**：Python 3.7+（无需安装任何第三方库）。

```bash
cd exam-ai-tutor
python server.py
# 浏览器打开 http://127.0.0.1:8000
```

然后在「使用说明」里填入你的 **DeepSeek API Key** 即可使用。

## 获取 DeepSeek API Key

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com)，手机号 / 微信注册。
2. 「充值」：按量计费，**先充 10 元即可使用很久**。
3. 「API Keys」→ 创建 Key，复制 `sk-…`。
4. 打开网站 →「使用说明」→ 粘贴 Key → 保存。

> 拍照识别会自动使用 DeepSeek 的 `deepseek-flash` 模型，无需额外配置视觉模型。

## 试卷库（基于你的往年试卷出题）

网站会把 `static/papers.txt` 作为「风格参考」加载，出模拟卷 / 举一反三时参考它的题型、难度、知识点。

- 里面已经放了 6 份南信大代表性试卷（高数、大物I、大物II），由本地 OCR 整理。
- 想增加试卷：把试卷文字追加到 `papers.txt`（`#` 开头的行是注释）。
- 获取试卷文字的方法：用本网站的「拍照识别」逐页识别，复制结果粘贴进去。

### 定期更新试卷库（推荐）

项目自带**试卷库维护工具**，以后拿到新试卷可以一条命令自动入库：

1. 把新试卷（PDF / 图片）放进 `papers_inbox/` 文件夹
2. 运行：
   ```bash
   pip install pymupdf rapidocr_onnxruntime   # 首次使用装一次
   python tools/add_papers.py
   ```
   工具会自动 OCR、按文件名去重，追加到 `static/papers.txt`
3. 重新打包 `static/` 并部署到 Netlify，网站就会参考新试卷

> 细节见 `papers_inbox/README.txt`。也可以直接把试卷发给我，我帮你识别更新。
