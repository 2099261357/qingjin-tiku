# 青衿题库 · 高数 / 大物 AI 伴学

一个可本地运行、可上传 GitHub 的学习辅助网站。基于大模型 API（默认 DeepSeek），
面向**高等数学、大学物理**，提供：拍照识别、题目解答、举一反三、深度思考、生成模拟卷，以及留言反馈。

> **重要声明（用户自备 Key）**
> 本工具本身不提供 AI 服务，也不储存任何大模型密钥。所有解题、举一反三、深度思考与模拟卷，
> 均由「你本人填写的第三方 API Key」调用大模型生成，由此产生的调用费用由该 Key 所属账户自行承担。
> 你的 Key 只保存在你自己的浏览器（localStorage）中，不会上传到服务器。

---

## 功能

| 功能 | 说明 |
|------|------|
| **拍照识别** | 拍照/上传题目图片，视觉模型识别文字后自动解答 |
| **解题** | 思路分析 → 分步解答 → 一题多解 → 易错提醒 → 思维拓展 |
| **举一反三** | 生成「基础变式」+「创新变式」，每道标注考察的思维点并附解答 |
| **深度思考** | 讲透概念本质、多角度审视、主动做创新拓展、梳理知识脉络 |
| **出模拟卷** | 生成风格与往年真题相近的完整试卷，含「综合创新题」板块 |
| **留言反馈** | 用户可提交建议/报错，存于 `data/feedback.jsonl` |
| **演示模式** | 未设置 Key 时也能跑通全流程（不联网、不花钱） |

## 快速开始

**要求**：Python 3.7+（无需安装任何第三方库）。

```bash
# 1. 进入项目目录
cd exam-ai-tutor

# 2. 启动
python server.py

# 3. 浏览器打开
#    http://127.0.0.1:8000
```

> 要让局域网内的同学访问，可这样启动：`HOST=0.0.0.0 python server.py`，然后用你的局域网 IP 访问。
> （注意：这会让你电脑上的 8000 端口暴露在局域网内。）

## 获取 API Key（含充值步骤）

1. **注册**：打开 [DeepSeek 开放平台](https://platform.deepseek.com)，用手机号或微信注册 / 登录。
2. **充值**：进入「充值」页面，选择金额完成支付（按量计费，**先充 10 元即可使用很久**）。
3. **创建 Key**：进入「API Keys」→「创建 API Key」，复制生成的一串 `sk-…`。
4. **填入本页**：打开网站 →「使用说明」→ 粘贴到「API Key」→ 点「保存」。
5. **选择模型**：默认 `deepseek-chat`（快、便宜）；难题/深度思考可切换 `deepseek-reasoner`（推理更强、更慢更贵）。

> **拍照识别需要一个「视觉模型」**：DeepSeek 标准 API 不支持图片。推荐用**免费的智谱 GLM-4V-Flash**
> （接口地址 `https://open.bigmodel.cn/api/paas/v4`，模型 `glm-4v-flash`，注册即免费用）；
> 也可用通义千问 Qwen-VL（`qwen-vl-plus`）。在「使用说明」里单独配置。

## 后端接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查 |
| POST | `/api/chat` | 转发到 OpenAI 兼容接口（默认 DeepSeek），需 `Authorization: Bearer <key>` |
| GET | `/api/feedback?limit=100` | 读取最新留言 |
| POST | `/api/feedback` | 提交留言 `{"nickname":"…","content":"…"}` |

## 部署上线（随时随地可访问）

已内置 **Vercel 免费托管**所需的全部文件（`api/`、`vercel.json`），部署后你会得到固定网址
`https://xxx.vercel.app`，任何网络都能打开。

**完整图文教程见 [DEPLOY.md](DEPLOY.md)**，大概流程：
1. 把代码推到 GitHub；
2. Vercel 连接该仓库，一键部署；
3. 在 Upstash 建一个免费 Redis，配置环境变量（留言功能用）。

> 部署只需注册 GitHub / Vercel / Upstash 三个免费账号，约 20 分钟。
> 上线后仍为「各人自带 Key」，AI 费用各人自理，你不承担他人费用。

## 成本说明（BYOK 模式）

- 你自己的 AI 费用：DeepSeek 按 token 计费，**自己刷题单题约几分钱，充 10 元够用很久**。

- 服务器：免费层即可做到 ≈0 成本。

## 隐私与安全
